# Проверка 0.4.0-beta

## Подтверждено программно

- Сборка Java, ресурсов и DEX прошла. Подпись v3 и выравнивание APK проверены.
- **54 JVM-проверки прошли:** 15 для паролей/календаря, 13 для двухминутного срока, 26 для URL и режима браузера.
- Проверены HTTPS Google Play, market/intent/native-схемы, ссылки передачи в приложение, страницы скачивания TikTok, регистр имён хостов и кодированные пути. Обычные TikTok/Telegram HTTPS-адреса разрешаются; домены сравниваются по границам, а не по случайному совпадению в строке.
- Проверена сборка настольного User-Agent с сохранением версии установленного Chromium. Это проверка формата запроса, не доказательство работы ленты TikTok.
- Срок остаётся 120 секунд по elapsedRealtime с повторной проверкой до показа страницы. По исходникам Home, сворачивание через меню и Back без истории сохраняют Activity; немедленная блокировка выполняется отдельным явным действием.
- Исправление первоначального DecorView/WindowInsetsController из 0.3.1 сохранено.
- Проверен байткод: Back вызывает moveTaskToBack, а не lockToTracker; опасного вызова Window.getInsetsController нет. Сертификат совпадает с 0.3.1. Манифест готового APK содержит только INTERNET, одну Activity и не содержит фоновых служб/администратора/приёмников.

## Попытка живой проверки TikTok

Запущен локальный headless Chromium через Playwright с чистыми анонимными контекстами, мобильным и настольным User-Agent и окном 412×915. Оба перехода на https://www.tiktok.com/foryou завершились тайм-аутом навигации 30 секунд. Страница не загрузилась, видео не воспроизводились, переход за второе видео проверить не удалось.

Поэтому нельзя утверждать, что версия для ПК снимает ограничение пользователя, что вход в TikTok работает или что доступен весь функционал приложения. Нативный TikTok не встроен; скрытый рабочий профиль не создаётся.

## Ограничения проверки

На телефоне/эмуляторе новая версия не запускалась. Реальные редиректы WebView, состояние сайтов, Back/Home на One UI 8, выгрузка приложения системой и очистка веб-хранилищ требуют проверки на устройстве.

Если Android уничтожит Activity/процесс, закрытый вход не восстанавливается автоматически даже до истечения двух минут. Если процесс заморожен, выполнение очистки может задержаться, но срок проверяется до показа веб-окна при возврате. Cookie сайтов сохраняются по умолчанию; серверная история не удаляется.
