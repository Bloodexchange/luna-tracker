# Проверка 0.2.0-beta — только веб

## Выполнено локально

- Java-код и ресурсы собраны с JDK 17, Android SDK 35, Build Tools 35.0.0. D8 сформировал DEX.
- 15 JVM-проверок паролей и расчёта цикла прошли. Семь проверок удалённой профильной функции больше не входят в тесты.
- Подпись v3 и выравнивание APK проверены.
- Сертификат подписи совпадает с 0.1.0. Проверен манифест готового APK: единственное разрешение INTERNET, одна MainActivity, без администраторов, служб и приёмников. Старых профильных классов в архиве классов нет.
- Для классов каждой сборки используется новый каталог: удалённые классы не подмешиваются из старого build/classes.
- По исходникам проверены сброс дополнительного входа при onPause, уничтожение WebView, запрос очистки истории и дискового кэша.
- Добавлен сохраняемый переключатель удаления веб-входов. Во время удаления cookie новый веб-доступ блокируется. Флаг незавершённой очистки сохраняется перед приватной веб-сессией и позволяет повторить очистку после перезапуска.

## Что не проверено

Новая версия не запускалась на телефоне или эмуляторе. Не подтверждены фактическая очистка всех типов хранилищ конкретного Android System WebView, повторная авторизация Telegram/TikTok, обработка аварийного завершения на конкретной прошивке и обновление на устройстве со старым активным администратором.

Очистка WebStorage запрашивается через Android API без отдельного callback, подтверждающего удаление каждого вида данных. Подтверждение callback CookieManager относится к операции над cookie. Это не обещание физического удаления всех следов или удаления серверной истории.

Перед обновлением удалите старый рабочий профиль по [инструкции](README.md), предварительно сохранив его нужные данные. Устанавливайте APK поверх обычной копии Луны без портфеля. Приложение само не удаляет профиль.
