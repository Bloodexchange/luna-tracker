# Проверка сборки 0.1.0-beta

Дата: 20 ноября 2026. Среда: Windows, локальная сборка.

21 ноября 2026 повторно сверены SHA-256, подпись и выравнивание APK. Файлы исходного кода и ресурсов не новее собранного APK.

## Выполнено

- Проверены контрольные суммы скачанных Android Build Tools 35.0.0, платформы Android 35 и JDK 17 по метаданным официальных источников. Для JDK учтён точный размер из HTTP Content-Range: размер в метаданных поставщика оказался округлён.
- Ресурсы скомпилированы и связаны `aapt2`; весь Java-код скомпилирован с Android SDK. D8 сформировал DEX.
- **22 проверки прошли**: корректный/неверный пароль, отсутствие открытого пароля в записи, очистка входного массива пароля, случайные соли, отказ при повреждённой записи, ограничение параметров KDF, границы цикла и будущие даты, переходы между экранами приложения, уход в другое приложение, уход в фон и отсутствие подтверждения запуска.
- `apksigner verify --verbose`: подпись **v3** корректна, один подписант. Для минимального Android 10 подпись v3 поддерживается.
- `zipalign -c -p 4`: выравнивание прошло проверку.
- Включены `FLAG_SECURE`, исключение Луны из недавних задач, запрет резервного копирования и cleartext HTTP. Секретный сеанс не сохраняется в хранилище и сбрасывается в `onPause`.
- При просмотре исходников проверена отмена результата асинхронной проверки пароля после ухода в фон: код отклоняет ответ со старым номером поколения. Этот сценарий не запускался в Android.
- Служба управления APK не экспортируется другим приложениям. Профильные операции проверяют статус profile owner. Служб специальных возможностей в конечной сборке нет.

## Результат

- Файл: [Luna-0.1.0.apk](https://github.com/Bloodexchange/luna-tracker/releases/download/v0.1.0-beta/Luna-0.1.0.apk)
- Размер: 41 581 байт.
- SHA-256: `aab3429df467a0867e8d767a45f040b9a5e09fcc4824c7f5fd707fd61d2305c7`
- Минимальная версия: Android 10 / API 29. Целевая: Android 15 / API 35.
- Запуск сторонних APK в защищённом профиле ограничен Android 13+; на более ранних версиях доступны календарь и веб-раздел.

## Не проверено в Android

Установка, внешний вид, создание рабочего профиля, выдача доступа к статистике, фактическое скрытие APK, события UsageStats на прошивке, уведомления и вход в Telegram/TikTok **не проверялись на телефоне или эмуляторе**. Модель телефона и версия Android не предоставлены. Проверка исходников и JVM-тесты не заменяют эти проверки.

Это первая beta, которую нужно проверить на своём устройстве по [инструкции](README.md). До такой проверки нельзя полагаться на неё как на подтверждённое средство скрытия приложений. Полная невидимость в системных настройках и удаление всех чужих недавних задач не заявляются.
