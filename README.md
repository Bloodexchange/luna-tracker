# Луна · Android beta

Локальный трекер цикла с дополнительным входом и управлением приложениями в отдельном рабочем профиле Android. Без root, сервера, аналитики и регистрации по e-mail. Это первая тестовая сборка, а не гарантия не обнаруживаемости.

**[Скачать APK 0.1.0-beta](https://github.com/Bloodexchange/luna-tracker/releases/download/v0.1.0-beta/Luna-0.1.0.apk)** · [Релиз и контрольная сумма](https://github.com/Bloodexchange/luna-tracker/releases/tag/v0.1.0-beta)

## Установка и первый вход

1. Перенесите `artifacts/Luna-0.1.0.apk` на телефон и установите. Android может запросить разрешение на установку из выбранного источника.
2. Создайте обычный локальный аккаунт. Затем задайте дополнительный логин и пароль от 12 символов либо пропустите этот шаг.
3. В календаре нажмите **Выйти из аккаунта**. В той же форме введите дополнительную пару логина и пароля.
4. При уходе в фон закрытый вход сбрасывается. Луна возвращается к обычному календарю. Для повторного доступа снова выйдите из обычного аккаунта и введите дополнительную пару.

Заводских логинов, паролей и обходного входа нет. Восстановления забытого пароля через сервер тоже нет. Приложение хранит один обычный и один дополнительный локальный аккаунт. Данные двух копий Луны после создания рабочего профиля не синхронизируются.

## Вариант 1: веб-сервисы внутри Луны

В закрытом разделе доступны Telegram Web и TikTok Web. Отдельные APK этих сервисов не устанавливаются: в списке установленных приложений присутствует Луна. Уже установленные Telegram/TikTok в личном профиле это не скрывает.

Уход в другое приложение уничтожает экран браузера. Собственные уведомления, внешние переходы через `intent:`, геолокация, камера, микрофон и скачивание файлов отключены. Веб-версии могут иметь ограничения авторизации, звонков, загрузок или просмотра видео; совместимость зависит от сервиса, сети и Android System WebView.

Сессии сайтов сохраняются внутри данных приложения, поэтому после дополнительного входа не обязательно каждый раз входить в Telegram. Кнопка очистки веб-данных предназначена для выхода из сайтов. Сайты сами обрабатывают данные при обращении к ним. Луна не передаёт данные трекера сайтам.

## Вариант 2: настоящие Android-приложения

Нужны поддержка рабочего профиля телефоном и Android 13+ для запуска APK с принудительным запретом обычных уведомлений. Сам трекер и веб-раздел работают с Android 10. Если рабочий профиль уже занят корпоративным ПО, Shelter, Island и т. п., второй создать обычно нельзя. Ничего существующего автоматически не удаляется.

1. В закрытом разделе нажмите **Создать отдельный профиль**. Подтвердите системный диалог Android. Профиль будет виден в настройках.
2. Откройте **копию Луны со значком портфеля**. Используйте дополнительный логин и пароль, заданные перед созданием профиля. Если производитель не передал настройки, приложение предложит создать локальные аккаунты заново.
3. В закрытом разделе нажмите **Настроить блокировку при выходе** и разрешите Луне **доступ к статистике использования** именно рабочего профиля. При отсутствии этого разрешения запуск защищённых APK блокируется. Во время сеанса работает foreground-служба: Android показывает её нейтральный индикатор «Луна». Служба не читает сообщения, содержимое экрана и нажатия.
4. Вернитесь, заново войдите дополнительным логином. Нажмите **Установить APK в этот профиль**. Android отдельно запросит разрешение на установку из Луны; после его включения повторите вход и установку. Файл должен быть доступен системному выбору файлов рабочего профиля. Луна не скачивает APK с неизвестных сайтов и не копирует личные приложения автоматически.
5. Новое несистемное приложение в профиле автоматически добавляется в защищённый список и скрывается. Уже установленные приложения можно добавить кнопкой **Выбрать установленные приложения**.
6. Запускайте приложение только из закрытого списка. Луна сначала скрывает другие защищённые APK, затем временно делает выбранный доступным, запрещает обычные уведомления и запускает его. При получении события ухода приложения с переднего плана или при выключении экрана служба снова скрывает защищённые APK. Смена экранов внутри одного приложения учитывается отдельно.

В скрытом состоянии APK недоступен для запуска, его данные остаются в профиле. Удаление рабочего профиля стирает приложения и их данные. Чтобы отказаться от управления, удалите рабочий профиль через настройки Android, предварительно сохранив нужное содержимое. Приложение не управляет личной частью телефона.

## Существенные ограничения

- Рабочий профиль, сама Луна, её служба и выданные разрешения видны в системных настройках. Скрытые пакеты могут обнаруживаться системными инструментами, ADB и анализом устройства. Обещания полной невидимости нет.
- Оригиналы приложений в личном профиле остаются на месте. Удалять их вручную следует только после проверки отдельной установки и сохранности нужных данных; приложение их не удаляет.
- На время использования APK его пакет доступен системе. Профильный контроллер не может сделать работающее стороннее приложение невидимым для самой ОС.
- Луна исключена из недавних задач и запрещает снимки экрана. Для запуска сторонних APK запрашивается исключение из недавних, но приложение может создавать собственные задачи. Удаление всех чужих карточек и истории Android не гарантируется и не заявляется.
- Автоблокировка зависит от работающей фоновой службы, доступа к статистике использования и поведения прошивки. Отключение/принудительная остановка службы, аварийное завершение процесса или задержка событий ОС могут оставить ранее запущенный APK доступным. После перезагрузки, нового запуска службы и возвращения в Луну выполняется повторное скрытие. Режим нескольких окон и системные панели могут не давать обычного события ухода приложения с переднего плана. Перед реальным использованием проверьте сценарии ниже на своём телефоне.
- Режим строгий: системные диалоги, панель уведомлений, вход с переходом в другое приложение и запросы разрешений могут завершать сеанс. Это ограничивает отдельные сценарии сторонних приложений.
- Запрет `POST_NOTIFICATIONS` закрывает обычные уведомления Android 13+, но Android имеет специальные исключения, например для некоторых медиасессий. Скрытие APK завершает доступность приложения; гарантировать абсолютное отсутствие всех системных индикаторов нельзя.
- Локальные настройки, пароли в виде PBKDF2-хешей и заметки зашифрованы AES-GCM с ключом Android Keystore. Файлы WebView хранятся в системной песочнице приложения; отдельного шифрования всей базы WebView дополнительным паролем нет. Резервное копирование и перенос данных Android выключены.
- Это календарь наблюдений, не средство диагностики или контрацепции.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. В этой рабочей среде они размещаются вне исходников в `%LOCALAPPDATA%/LunaBuildTools`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Сборка не использует Gradle и сторонние библиотеки: `aapt2`, `javac`, D8, `zipalign`, `apksigner`. Скрипт выполняет тесты паролей и календаря, подписывает APK, проверяет подпись и выравнивание. Ключ подписи хранится отдельно от проекта в каталоге инструментов `signing`; для обновлений нужно сохранить именно этот ключ. Не публикуйте ключ и его пароль.

## Что проверить на телефоне

1. Обычный вход, дополнительный вход, неверный пароль, ограничение повторных попыток.
2. Home, недавние, блокировка экрана и возвращение: должен показываться календарь; для закрытого раздела снова нужен пароль.
3. Принудительно остановить и снова запустить Луну: закрытого сеанса быть не должно.
4. Создание профиля, установка тестового APK, скрытие и повторный запуск. Проверить поиск, раздел приложений и недавние именно на своей прошивке.
5. Запущенный профильный APK → Home / другое приложение / экран блокировки: пакет должен снова скрываться. При сбое не считать устройство защищённым.
6. Проверить запрет обычных уведомлений и ограничения сторонних APK, отдельно проверить медиаплееры/звонки.
7. Войти в веб-сервис, уйти в фон и вернуться: веб-экран не должен восстанавливаться до нового дополнительного входа.

## Основания Android API

- [DevicePolicyManager.setApplicationHidden](https://developer.android.com/reference/android/app/admin/DevicePolicyManager#setApplicationHidden(android.content.ComponentName,java.lang.String,boolean)) — скрытие пакетов владельцем профиля.
- [Рабочие профили](https://developer.android.com/work/managed-profiles) — отдельная область Android.
- [Notification runtime permission](https://developer.android.com/develop/ui/views/notifications/notification-permission) — разрешение уведомлений Android 13 и исключения.
- [UsageStatsManager](https://developer.android.com/reference/android/app/usage/UsageStatsManager) — события открытия и закрытия приложений; доступ пользователь разрешает в настройках.
